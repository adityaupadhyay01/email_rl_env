Email Threat Triage

A reinforcement-learning environment where an agent investigates each email, then decides to quarantine it, allow it, or hand it to a human.

Open the live triage demo: paste an email, watch the agent collect evidence, and see it quarantine or escalate the message.

Held-out test set: 783 real public emails

283 phishing (phishing_pot), 150 spam and 350 genuine emails (SpamAssassin). Never used for training or tuning. Same tools and rewards for every agent.

Training the policy (REINFORCE)

Validation reward per email, 9-epoch average, 3 seeds.

Indian scenario set: 34 hand-written emails
